# tech-learning-lab

> 各类技术栈的快速上手指南、实践 Demo 与技术探索

## 项目定位

这是一个**技术学习实验室**，目标是帮助开发者快速掌握各类技术栈的生产核心功能。

每个技术模块都遵循统一的方法论：
1. **环境搭建** — 确保能跑起来（安装 + 验证 + 平台差异）
2. **技术背景与选型对比** — 理解技术定位和适用场景
3. **生产高频功能筛选** — 只学真正在用的，跳过边缘功能
4. **整合教学文档 + 可运行代码** — 学一个练一个，教学与代码严格对应
5. **综合实战 Demo** — 串联各模块，贴近真实业务
6. **实践 Q&A 沉淀** — 动手过程中产生的疑问持续补充

这套方法论的详细流程见 [`learn-tech-SKILL.md`](./learn-tech-SKILL.md)，可用于指导任何新技术的学习。
